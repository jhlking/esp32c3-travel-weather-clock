## 2.0 版本新增

- **商店系统**
- **花园系统**
- **自定义铃声编辑功能**
- **万年历模式**

## 显示界面（实拍可见）

配图 `00-hero.jpg` / `01-assembled-display.jpg` 中可见：

- 顶部：`15:32` 时间；`06月04日 周四` 日期与星期；`26 ~ 36℃` 温度区间；天气图标。
- 中部：天气主题插画（蓝天、云、草地、骑行人物）。
- 底部：定位图标 + 城市名（如 `广州`）；房屋图标 + 温度（如 `33℃`）。

推测包含天气查询与城市切换（联网获取），但网络接口与实现未公开，此处不做断言。

## 复刻者注意事项

- 固件源码不在本仓库，也无法从原工程页面附件获取；请联系原作者。
- 屏幕驱动为 ST7789 / 4-SPI；实际初始化参数（色彩模式、扫描方向、偏移）必须与屏幕批次匹配。
- 3 个蜂鸣器与自定义铃声功能相关，具体 GPIO 与音效编码需查原工程源码。
- 温度数据来自热敏电阻分压，需原工程的查表/公式才能换算为摄氏度。
